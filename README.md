# Lemvori Shift — графіки чергувань + Telegram

Безкоштовний у межах лімітів Cloudflare Workers + D1 застосунок із сайтом адміністратора та приватним Telegram-ботом. Дизайн — темний, українська мова. **Призначений для графіків роботи, не для медичних записів пацієнтів.**

## Що є в першій версії

- Місячний календар лише для добових (24-годинних) чергувань із бригадами та повним складом, кнопка «Наступний місяць».
- Перегляд повного складу кожного чергування, додавання, редагування, видалення, друк графіка.
- Реєстр працівників із номерами +380 і пошуком за ПІБ/номером. Працівник підтверджує свій номер через Telegram-кнопку «Поділитися моїм номером» (тільки власний контакт). Запасний варіант — індивідуальний одноразовий код, діє 24 години.
- Команди `/my`, `/my next`, `/month`, `/month next`, `/next`, `/team`, `/tomorrow`, `/reminders on`, `/reminders off`.
- Особисте нагадування наступного дня перед зміною: о 18:00–22:00 за київським часом (перша доступна перевірка після 18:00); ім'я бригади, час, колеги. Зазвичай надсилання близько 18:00. Немає потреби тримати комп'ютер увімкненим.
- Адміністративна панель захищена паролем, код прив'язки не зберігається у відкритому вигляді; секрет webhook перевіряється.

> ВАЖЛИВО: хмарні безкоштовні тарифи мають квоти, Cron Trigger і доставка Telegram не гарантують точного часу до хвилини або 100% SLA. Для невеликої команди ця архітектура практична; для критичного чергування не покладатися лише на бота.

## Розгортання лише через браузер (без увімкненого ПК/сервера)

### 1. Підготуй бота

У Telegram відкрий **@BotFather** → `/newbot` → створи бота → збережи **BOT TOKEN**. Не надсилай токен у чат і не клади в GitHub.

### 2. Створи базу D1

У [Cloudflare Dashboard](https://dash.cloudflare.com/) → **Storage & databases → D1** → Create Database → назва `lemvori-shift-db`. Скопіюй **Database ID** (UUID).

Відкрий нову базу → **Console**. Відкрий `schema.sql` із цього проєкту і встав SQL у консоль, натисни Execute. Якщо консоль не дозволяє виконати все одразу, виконуй окремі `CREATE TABLE` та `CREATE INDEX` по одному. Не пропускай таблиці; їх має бути 6: `employees`, `employee_phones`, `shifts`, `shift_members`, `reminder_log`, `login_failures`. Якщо база вже існує, Worker автоматично створить лише нову таблицю `employee_phones` за першого звернення; наявні графіки не стираються.

### 3. Завантаж сайт на GitHub через браузер

1. Створи приватний репозиторій на [github.com/new](https://github.com/new).
2. Розпакуй ZIP, вибери **вміст** папки `lemvori-shift` і завантаж у GitHub (**Add file → Upload files**) зі збереженням структури папок `src/`, `public/`, `tests/` (для папок використай drag-and-drop). Не завантажуй `.dev.vars`.
3. У GitHub відкрий файл `wrangler.jsonc` → Edit (олівець), заміни `REPLACE_WITH_CLOUDFLARE_D1_DATABASE_ID` на реальний ID бази D1, збережи зміни.

### 4. Підключи GitHub до Cloudflare Workers

У Cloudflare Dashboard → **Workers & Pages → Create → Import a repository** (назви в інтерфейсі можуть трохи відрізнятися). Обери щойно створений GitHub-репозиторій.

- Worker name: `lemvori-shift` (має збігатися з `name` у `wrangler.jsonc`).
- Deploy command: `npx wrangler deploy`.
- Build command: залиш порожнім, якщо не вимагається, — проєкт без кроку збирання фронтенду.

Після успішного деплою сайт буде на адресі на зразок `https://lemvori-shift.<your-subdomain>.workers.dev`. Адресу потрібно брати саме з Cloudflare; не вгадуй її.

### 5. Додай 4 секрети Cloudflare (НЕ на GitHub)

Cloudflare → Workers & Pages → `lemvori-shift` → Settings → **Variables and Secrets** → Add → **Secret**:

| Назва | Що ввести |
|---|---|
| `ADMIN_PASSWORD` | Надійний унікальний пароль адміністратора (не менш ніж 16 символів) |
| `SESSION_SECRET` | Випадковий довгий рядок (не менш ніж 32 символи) |
| `TELEGRAM_BOT_TOKEN` | Токен, який видав @BotFather |
| `TELEGRAM_WEBHOOK_SECRET` | Випадковий рядок із латинських букв, цифр, `-`, `_`, 24–64 символи |

Рекомендація: згенеруй два різні секрети локальним менеджером паролів. Зберігай їх окремо. **Не публікуй токени.**

### 6. Запусти

1. Відкрий адресу твого Worker's `workers.dev`, увійди з `ADMIN_PASSWORD`.
2. У вкладці **Telegram-бот** натисни **Підключити Telegram webhook**. Він автоматично зареєструє адресу в Telegram.
3. У вкладці **Працівники** додай ПІБ і номер телефону у форматі `+380XXXXXXXXX`.
4. Працівник відкриває бота й пише `/start`, натискає «📱 Поділитися моїм номером». Telegram має передати власний контакт; чужі номери відхиляються. Якщо у працівника іноземний номер, використай **Код Telegram** → `/start КОД`.
5. Створи добове чергування, вибери дату й час початку, бригаду та познач усіх, хто чергує разом; завершення автоматично припадає на той самий час наступного дня. Для наступного місяця натисни **Наступний місяць**.
6. У профілі працівника натисни **Тест**, щоб перевірити доставку.
7. У Cloudflare → Worker → Triggers перевір Cron `0 * * * *`. Він заданий у `wrangler.jsonc`; Cloudflare виконує вираз за UTC, додаток сам перераховує київський час із переходом на літній час.

### Локальне розроблення (якщо захочеш)

Потрібні Node.js 20+ і npm:

```bash
npm install
cp .dev.vars.example .dev.vars
# заповни .dev.vars локально
npx wrangler d1 create lemvori-shift-db
# встав Database ID у wrangler.jsonc
npm run db:local
npm run dev
npm test
```

Для інсталяції схеми на хмарній D1 із CLI: `npm run db:remote`.

## Ролі й конфіденційність

**Адміністратор** — через сайт може редагувати всю команду й загальний графік. **Працівник** — через персональний Telegram бачить свій графік і спільний графік усієї команди; особисті нагадування надходять лише прив'язаному акаунту. Telegram можна підключити за підтвердженим власним номером або персональним одноразовим кодом. Номери зберігаються тільки у приватній Cloudflare D1, показуються лише адміністратору й ніколи не потрапляють до GitHub. Видалення/деактивація працівника припиняє його бот-доступ. Не додавай ПІБ пацієнтів чи чутливу медичну інформацію до приміток змін.

## Якщо щось не працює

- **Помилка 503 D1** — немає DB binding або схеми. Перевір `wrangler.jsonc`, DB ID і таблиці.
- **Помилка 503 ADMIN_PASSWORD** — додай `ADMIN_PASSWORD` і `SESSION_SECRET` як Secrets Worker.
- **Webhook не підключається** — перевір `TELEGRAM_BOT_TOKEN`, `TELEGRAM_WEBHOOK_SECRET`, потім кнопку підключення.
- **Підключення з кодом не вдається** — код діє 24 години та одноразовий; створити новий у панелі.
- **Нагадування немає** — працівник має підключити Telegram, увімкнути `/reminders on`, бути активним, мати зміну завтра; перевір Cron Trigger і Workers Logs, квоти Cloudflare та можливі помилки Telegram.
- **База в GitHub** — не потрібно й не слід комітити базу: дані зберігаються в Cloudflare D1.

## Можливості для наступних версій

Шаблон «доба через троє», автогенерація графіка на місяць, зміна/обмін чергуваннями за погодженням, ролі старшого зміни, експорт Excel/PDF, групова нотифікація при заміні, архів та імпорт графіків з таблиці.
## Перенесення паперового графіка з фото

Надішли фото графіка в чат, щоб розібрати прізвища, дати, бригади та перевірити неоднозначні записи. Після звірки їх можна перенести в адміністративний календар. Сам сайт поки **не розпізнає фото автоматично** — це не слід плутати з готовим імпортом.
